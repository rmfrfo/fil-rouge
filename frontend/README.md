# TechCorp RH - Frontend

Projet créé avec `ng new` (Chemin A)

## Pré-requis

- Installer [NodeJS](https://nodejs.org/en/download?version=24.22.0) v24.22.0
- Installer [Angular CLI](https://github.com/angular/angular-cli) `npm install -g @angular/cli`

## Installation

- Clonez le dépôt
- `cd frontend`
- `ng serve`
